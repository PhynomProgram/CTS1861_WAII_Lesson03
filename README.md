Design for One: Persona-Driven Web Page Redesign
Introduction
User-Centered Web Design focuses on creating websites that prioritize real user needs, behaviors, and limitations rather than designer assumptions. In this assignment, you will apply core Lesson 3 concepts—personas, usability, cognitive psychology, and iterative design—to redesign a webpage for a specific user type. This assignment aligns with course outcomes by strengthening your ability to analyze user requirements and implement design decisions using HTML and usability best practices. Professionally, this mirrors real-world web design workflows where designers must justify decisions based on user needs, not personal preference.

Directions
Review Lesson 3 materials related to User-Centered Web Design, personas, usability, and cognitive psychology.
Select one persona from the options below and treat this persona as your primary user throughout the redesign process:

Persona Option A: Mobile-Only User
Accesses websites exclusively on a smartphone
Frequently on the go and interacts with content using touch
Needs clear hierarchy, readable text, and minimal scrolling
Persona Option B: Older Adult User
May have reduced vision or motor precision
Prefers clear navigation, strong contrast, and readable font sizes
Values clarity and simplicity over visual complexity
Persona Option C: First-Time Visitor
Has no prior familiarity with the website or its content
Needs immediate context, clear purpose, and intuitive navigation
Easily frustrated by clutter or unclear labeling
Persona Option D: Accessibility-Focused User
May rely on assistive technologies or accessible design practices
Requires meaningful structure, readable content, and logical layout
Benefits from consistent navigation and reduced cognitive load

Open the page Lesson03Assignment.html in your browser and evaluate how effectively it supports your selected persona’s goals, limitations, and expectations. This page is usable but flawed on purpose so learners can meaningfully apply personas, usability, cognitive psychology, accessibility, and mobile considerations from Lesson 3.
Identify usability challenges related to attention, perception, memory, accessibility, or mobile use that may negatively affect your persona’s experience.
Modify the webpage’s HTML and content to better support your persona, making intentional design decisions that improve usability and user satisfaction.
Inside the <head> section of your HTML file, add a custom meta tag identifying the persona you selected. 

Required Meta Tab Format (example)
<meta name="persona" content="Mobile-Only User">

Review and refine your redesigned page by viewing it from your persona’s perspective and making improvements as needed.
